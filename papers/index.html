About / 关于

一个可以一直加下去的中文论文库

页面不是一次性写死的长文，而是由共享的排版系统、逐篇的原文／元数据与一个小型构建脚本组成。新增一篇论文，只需要新建目录、放入图片与正文，再运行一次构建。

视觉上沿用暖纸张、中文衬线标题与青绿主色的编辑风格；技术上保持零前端框架、零外部依赖，双击 HTML 即可离线阅读。

  • 论文页共享同一套版式、目录、代码高亮、公式与灯箱交互。
  • 内容源写在 content.md，公式用 LaTeX，构建时预渲染为 KaTeX。
  • 论文库由 paper.json 自动收录，支持按关键词与标签筛选。
  • 构建只需要 Node 与 Python，产物是可直接打开的静态 HTML。
