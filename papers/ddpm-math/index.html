Abstract / 导读

DDPM 的核心并不是“训练一个网络直接画图”，而是把生成问题改写成一条从数据到噪声、再从噪声回到数据的概率链。前向过程固定、可解；逆向过程用神经网络近似；训练目标来自变分下界；最终的学习信号可以化简成“预测每一步加入的噪声”。本文按“前向 → 后验 → ELBO → 噪声回归 → score → 采样”的顺序，把这套数学完整拆开。

01生成问题：为什么要一条链 #

我们有一批来自未知分布 pdata(x0)p_{\mathrm{data}}(\mathbf{x}_0)pdata​(x0​) 的图像 x0\mathbf{x}_0x0​，想学一个模型 pθ(x0)p_\theta(\mathbf{x}_0)pθ​(x0​)，使它能够采样出类似的数据。

DDPM 引入一组与图像同维的潜变量

x1,x2,…,xT\mathbf{x}_1,\mathbf{x}_2,\ldots,\mathbf{x}_Tx1​,x2​,…,xT​

并定义两条链：

  • 前向过程 q(x1:T∣x0)q(\mathbf{x}_{1:T}\mid\mathbf{x}_0)q(x1:T​∣x0​)：固定不变，逐步向图像加高斯噪声；
  • 逆向过程 pθ(x0:T)p_\theta(\mathbf{x}_{0:T})pθ​(x0:T​)：带参数，学习从噪声逐步去噪。

前向过程把复杂的数据分布逐渐抹平成简单的标准高斯；逆向过程则试图沿着相反方向，把标准高斯推回数据分布。生成模型就是逆向过程：

pθ(x0:T):=p(xT)∏t=1Tpθ(xt−1∣xt),p(xT)=N(0,I)p_\theta(\mathbf{x}_{0:T}) := p(\mathbf{x}_T)\prod_{t=1}^{T}p_\theta(\mathbf{x}_{t-1}\mid\mathbf{x}_t), \qquad p(\mathbf{x}_T)=\mathcal{N}(\mathbf{0},\mathbf{I})pθ​(x0:T​):=p(xT​)t=1∏T​pθ​(xt−1​∣xt​),p(xT​)=N(0,I)

训练目标是让 pθ(x0)p_\theta(\mathbf{x}_0)pθ​(x0​) 尽量接近 pdata(x0)p_{\mathrm{data}}(\mathbf{x}_0)pdata​(x0​)；但直接最大化 log⁡pθ(x0)\log p_\theta(\mathbf{x}_0)logpθ​(x0​) 需要对所有潜变量积分，无法直接计算。于是我们用变分推断，优化一个可计算的上界。

02前向过程：一条线性高斯链 #

定义噪声强度 β1,…,βT∈(0,1)\beta_1,\ldots,\beta_T\in(0,1)β1​,…,βT​∈(0,1)，并记

αt:=1−βt,αˉt:=∏s=1tαs\alpha_t := 1-\beta_t, \qquad \bar\alpha_t := \prod_{s=1}^{t}\alpha_sαt​:=1−βt​,αˉt​:=s=1∏t​αs​

前向一步是

q(xt∣xt−1)=N(xt;1−βt xt−1,βtI)q(\mathbf{x}_t\mid\mathbf{x}_{t-1}) = \mathcal{N}\left(\mathbf{x}_t;\sqrt{1-\beta_t}\,\mathbf{x}_{t-1},\beta_t\mathbf{I}\right)q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I)
(1)

也就是

xt=αt xt−1+βt ϵt,ϵt∼N(0,I)\mathbf{x}_t = \sqrt{\alpha_t}\,\mathbf{x}_{t-1} + \sqrt{\beta_t}\,\boldsymbol{\epsilon}_t, \qquad \boldsymbol{\epsilon}_t\sim\mathcal{N}(\mathbf{0},\mathbf{I})xt​=αt​​xt−1​+βt​​ϵt​,ϵt​∼N(0,I)

这里乘 αt\sqrt{\alpha_t}αt​​ 是为了让方差大致保持不变：如果 xt−1\mathbf{x}_{t-1}xt−1​ 的各坐标近似单位方差，那么 xt\mathbf{x}_txt​ 的方差也近似为 111。

由于每一步都是线性高斯的，整条链可以“跳步”采样。把上式反复展开，得到闭式：

q(xt∣x0)=N(xt;αˉt x0,(1−αˉt)I)q(\mathbf{x}_t\mid\mathbf{x}_0) = \mathcal{N}\left(\mathbf{x}_t;\sqrt{\bar\alpha_t}\,\mathbf{x}_0,(1-\bar\alpha_t)\mathbf{I}\right)q(xt​∣x0​)=N(xt​;αˉt​​x0​,(1−αˉt​)I)
(2)

等价地：

xt=αˉt x0+1−αˉt ϵ,ϵ∼N(0,I)\mathbf{x}_t = \sqrt{\bar\alpha_t}\,\mathbf{x}_0 + \sqrt{1-\bar\alpha_t}\,\boldsymbol{\epsilon}, \qquad \boldsymbol{\epsilon}\sim\mathcal{N}(\mathbf{0},\mathbf{I})xt​=αˉt​​x0​+1−αˉt​​ϵ,ϵ∼N(0,I)

这个式子非常重要：它说明任意噪声级别的 xt\mathbf{x}_txt​ 都可以由原图 x0\mathbf{x}_0x0​ 和一个标准高斯噪声直接构造，不需要真的跑 ttt 步前向。

当 ttt 很小时，αˉt≈1\bar\alpha_t\approx1αˉt​≈1，xt\mathbf{x}_txt​ 仍然很像原图；当 ttt 接近 TTT 时，αˉT≈0\bar\alpha_T\approx0αˉT​≈0，xT\mathbf{x}_TxT​ 近似纯噪声。噪声调度决定了这个“破坏”过程有多快。

前向过程没有任何可学习参数。这个选择不是偷懒，而是整个方法可解的前提：后验、ELBO、训练目标都依赖于前向过程是已知的线性高斯链。

03逆向过程与后验 #

逆向过程定义为

pθ(xt−1∣xt)=N(xt−1;μθ(xt,t),Σθ(xt,t))p_\theta(\mathbf{x}_{t-1}\mid\mathbf{x}_t) = \mathcal{N}\left(\mathbf{x}_{t-1};\boldsymbol{\mu}_\theta(\mathbf{x}_t,t),\boldsymbol{\Sigma}_\theta(\mathbf{x}_t,t)\right)pθ​(xt−1​∣xt​)=N(xt−1​;μθ​(xt​,t),Σθ​(xt​,t))
(3)

在 DDPM 中，协方差通常固定为 σt2I\sigma_t^2\mathbf{I}σt2​I，网络只学习均值 μθ\boldsymbol{\mu}_\thetaμθ​。为什么可以只学均值？因为当我们把逆向一步写成“从 pθp_\thetapθ​ 中采样”时，训练目标最终主要约束均值；固定方差已经能取得很好的样本质量，学习方差还会增加不稳定性。

后验到底在说什么 #

“后验”是给定观测后，隐变量的条件分布。这里我们真正需要的单步后验是

q(xt−1∣xt,x0)q(\mathbf{x}_{t-1}\mid\mathbf{x}_t,\mathbf{x}_0)q(xt−1​∣xt​,x0​)

翻成人话：

已知干净原图 x0\mathbf{x}_0x0​，又已知第 ttt 步的带噪图 xt\mathbf{x}_txt​，那么中间那张 xt−1\mathbf{x}_{t-1}xt−1​ 应该是什么样？

它不是确定值，而是一个分布：从 x0\mathbf{x}_0x0​ 到 xt\mathbf{x}_txt​ 的加噪路径不唯一，xt−1\mathbf{x}_{t-1}xt−1​ 有多个可能。

为什么可解 #

由贝叶斯公式：

q(xt−1∣xt,x0)∝q(xt∣xt−1) q(xt−1∣x0)q(\mathbf{x}_{t-1}\mid\mathbf{x}_t,\mathbf{x}_0) \propto q(\mathbf{x}_t\mid\mathbf{x}_{t-1})\,q(\mathbf{x}_{t-1}\mid\mathbf{x}_0)q(xt−1​∣xt​,x0​)∝q(xt​∣xt−1​)q(xt−1​∣x0​)

右边两项都是高斯：

  • q(xt∣xt−1)=N(αtxt−1,βtI)q(\mathbf{x}_t\mid\mathbf{x}_{t-1})=\mathcal{N}(\sqrt{\alpha_t}\mathbf{x}_{t-1},\beta_t\mathbf{I})q(xt​∣xt−1​)=N(αt​​xt−1​,βt​I)；
  • q(xt−1∣x0)=N(αˉt−1x0,(1−αˉt−1)I)q(\mathbf{x}_{t-1}\mid\mathbf{x}_0)=\mathcal{N}(\sqrt{\bar\alpha_{t-1}}\mathbf{x}_0,(1-\bar\alpha_{t-1})\mathbf{I})q(xt−1​∣x0​)=N(αˉt−1​​x0​,(1−αˉt−1​)I)。

两个高斯相乘，结果仍是高斯。配方后得到：

q(xt−1∣xt,x0)=N(xt−1;μ~t(xt,x0),β~tI)q(\mathbf{x}_{t-1}\mid\mathbf{x}_t,\mathbf{x}_0) = \mathcal{N}\left(\mathbf{x}_{t-1};\tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t,\mathbf{x}_0),\tilde\beta_t\mathbf{I}\right)q(xt−1​∣xt​,x0​)=N(xt−1​;μ~​t​(xt​,x0​),β~​t​I)
(4)

其中

μ~t(xt,x0)=αˉt−1βt1−αˉtx0+αt(1−αˉt−1)1−αˉtxt\tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t,\mathbf{x}_0) = \frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}\mathbf{x}_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\mathbf{x}_tμ~​t​(xt​,x0​)=1−αˉt​αˉt−1​​βt​​x0​+1−αˉt​αt​​(1−αˉt−1​)​xt​
(5)
β~t=1−αˉt−11−αˉtβt\tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_tβ~​t​=1−αˉt​1−αˉt−1​​βt​
(6)

直觉：两个高斯线索的精度加权 #

把后验均值理解成两个“线索”的加权融合：

  • 从 xt\mathbf{x}_txt​ 倒推：xt=αtxt−1+噪声\mathbf{x}_t=\sqrt{\alpha_t}\mathbf{x}_{t-1}+\text{噪声}xt​=αt​​xt−1​+噪声，所以 xt−1≈xt/αt\mathbf{x}_{t-1}\approx\mathbf{x}_t/\sqrt{\alpha_t}xt−1​≈xt​/αt​​，方差 βt/αt\beta_t/\alpha_tβt​/αt​，精度 αt/βt\alpha_t/\beta_tαt​/βt​；
  • 从 x0\mathbf{x}_0x0​ 前推：xt−1=αˉt−1x0+噪声\mathbf{x}_{t-1}=\sqrt{\bar\alpha_{t-1}}\mathbf{x}_0+\text{噪声}xt−1​=αˉt−1​​x0​+噪声，方差 1−αˉt−11-\bar\alpha_{t-1}1−αˉt−1​，精度 1/(1−αˉt−1)1/(1-\bar\alpha_{t-1})1/(1−αˉt−1​)。

后验的精度是两个精度之和：

A=αtβt+11−αˉt−1=1−αˉtβt(1−αˉt−1)A=\frac{\alpha_t}{\beta_t}+\frac{1}{1-\bar\alpha_{t-1}} =\frac{1-\bar\alpha_t}{\beta_t(1-\bar\alpha_{t-1})}A=βt​αt​​+1−αˉt−1​1​=βt​(1−αˉt−1​)1−αˉt​​

所以方差为

β~t=1A=βt(1−αˉt−1)1−αˉt\tilde\beta_t=\frac{1}{A} =\frac{\beta_t(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}β~​t​=A1​=1−αˉt​βt​(1−αˉt−1​)​

均值为“精度 × 估计”的加权平均，化简后正是式 (5)。这解释了那些看起来奇怪的系数：它们不是随手拼出来的，而是两个高斯信息源的精度权重。

采样时没有 x0\mathbf{x}_0x0​ #

后验公式需要 x0\mathbf{x}_0x0​，但生成时没有原图。于是用网络从 xt\mathbf{x}_txt​ 估计 x0\mathbf{x}_0x0​。由式 (2)：

x0=xt−1−αˉt ϵαˉt\mathbf{x}_0 = \frac{\mathbf{x}_t-\sqrt{1-\bar\alpha_t}\,\boldsymbol{\epsilon}}{\sqrt{\bar\alpha_t}}x0​=αˉt​​xt​−1−αˉt​​ϵ​

这一步是整个 DDPM 的核心：训练时用真实 x0\mathbf{x}_0x0​ 定义后验；采样时用网络估计的 x0\mathbf{x}_0x0​ 代替。

04变分上界：把生成写成可优化问题 #

直接最大化 log⁡pθ(x0)\log p_\theta(\mathbf{x}_0)logpθ​(x0​) 需要对 x1:T\mathbf{x}_{1:T}x1:T​ 积分。变分推断给出一个可计算的上界：

−log⁡pθ(x0)≤Eq[−log⁡pθ(x0:T)q(x1:T∣x0)]=:L-\log p_\theta(\mathbf{x}_0) \le \mathbb{E}_q\left[ -\log\frac{p_\theta(\mathbf{x}_{0:T})}{q(\mathbf{x}_{1:T}\mid\mathbf{x}_0)} \right] =:L−logpθ​(x0​)≤Eq​[−logq(x1:T​∣x0​)pθ​(x0:T​)​]=:L

把联合分布和近似后验都按马尔可夫链展开，并利用贝叶斯公式，可以把 LLL 拆成三项：

L=LT+∑t>1Lt−1+L0L=L_T+\sum_{t>1}L_{t-1}+L_0L=LT​+t>1∑​Lt−1​+L0​

其中

LT=DKL(q(xT∣x0) ∥ p(xT))L_T=D_{\mathrm{KL}}\left(q(\mathbf{x}_T\mid\mathbf{x}_0)\,\|\,p(\mathbf{x}_T)\right)LT​=DKL​(q(xT​∣x0​)∥p(xT​))
Lt−1=DKL(q(xt−1∣xt,x0) ∥ pθ(xt−1∣xt))L_{t-1}=D_{\mathrm{KL}}\left( q(\mathbf{x}_{t-1}\mid\mathbf{x}_t,\mathbf{x}_0) \,\|\,p_\theta(\mathbf{x}_{t-1}\mid\mathbf{x}_t) \right)Lt−1​=DKL​(q(xt−1​∣xt​,x0​)∥pθ​(xt−1​∣xt​))
L0=−log⁡pθ(x0∣x1)L_0=-\log p_\theta(\mathbf{x}_0\mid\mathbf{x}_1)L0​=−logpθ​(x0​∣x1​)

三项的含义分别是：

  • LTL_TLT​：先验匹配。前向方差固定、p(xT)=N(0,I)p(\mathbf{x}_T)=\mathcal{N}(\mathbf{0},\mathbf{I})p(xT​)=N(0,I) 时，它是常数，训练时可以忽略；
  • Lt−1L_{t-1}Lt−1​：逐步去噪。它比较真实后验与网络逆向一步，是训练的主项；
  • L0L_0L0​：数据重构。对应最后一步从 x1\mathbf{x}_1x1​ 解码到 x0\mathbf{x}_0x0​，在简化目标里并入 t=1t=1t=1 的回归项。

05从 KL 到噪声回归 #

在 pθp_\thetapθ​ 的方差固定为 σt2I\sigma_t^2\mathbf{I}σt2​I 时，Lt−1L_{t-1}Lt−1​ 是两个高斯之间的 KL。高斯 KL 的公式告诉我们，它只依赖均值之差：

Lt−1=Eq[12σt2∥μ~t(xt,x0)−μθ(xt,t)∥2]+CL_{t-1} = \mathbb{E}_q\left[ \frac{1}{2\sigma_t^2} \left\| \tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t,\mathbf{x}_0) -\boldsymbol{\mu}_\theta(\mathbf{x}_t,t) \right\|^2 \right]+CLt−1​=Eq​[2σt2​1​∥μ~​t​(xt​,x0​)−μθ​(xt​,t)∥2]+C
(11)

其中 CCC 与 θ\thetaθ 无关。于是训练网络就变成了“让预测均值接近真实后验均值”。

把式 (5) 和式 (7) 代入，并用

xt=αˉtx0+1−αˉtϵ\mathbf{x}_t=\sqrt{\bar\alpha_t}\mathbf{x}_0+\sqrt{1-\bar\alpha_t}\boldsymbol{\epsilon}xt​=αˉt​​x0​+1−αˉt​​ϵ

重参数化，可以得到

Lt−1=Ex0,ϵ[βt22σt2αt(1−αˉt)∥ϵ−ϵθ(xt,t)∥2]L_{t-1} = \mathbb{E}_{\mathbf{x}_0,\boldsymbol{\epsilon}} \left[ \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)} \left\| \boldsymbol{\epsilon} -\boldsymbol{\epsilon}_\theta(\mathbf{x}_t,t) \right\|^2 \right]Lt−1​=Ex0​,ϵ​[2σt2​αt​(1−αˉt​)βt2​​∥ϵ−ϵθ​(xt​,t)∥2]
(12)

这就是“预测噪声”的由来：均值之差经过代数化简后，正好变成噪声之差。

DDPM 进一步丢掉式 (12) 前面的权重，得到

Lsimple(θ)=Et,x0,ϵ[∥ϵ−ϵθ(αˉtx0+1−αˉtϵ,t)∥2]L_{\mathrm{simple}}(\theta) = \mathbb{E}_{t,\mathbf{x}_0,\boldsymbol{\epsilon}} \left[ \left\| \boldsymbol{\epsilon} -\boldsymbol{\epsilon}_\theta \left( \sqrt{\bar\alpha_t}\mathbf{x}_0+\sqrt{1-\bar\alpha_t}\boldsymbol{\epsilon},t \right) \right\|^2 \right]Lsimple​(θ)=Et,x0​,ϵ​[​ϵ−ϵθ​(αˉt​​x0​+1−αˉt​​ϵ,t)​2]

ttt 在 1,…,T1,\ldots,T1,…,T 中均匀采样。这个目标仍然是变分上界的一个加权版本，只是权重不同；实验上它训练的模型样本质量更好。直观原因是：式 (12) 的权重会压低小 ttt 项，让网络把注意力放在噪声更大、去噪更困难的时间步上。

06ε-预测就是 score matching #

这一节解释“为什么预测噪声能生成图像”，而不只是“能重建噪声”。

对每个 ttt，加噪后的数据分布记作

qt(xt)=∫q(xt∣x0)pdata(x0) dx0q_t(\mathbf{x}_t)=\int q(\mathbf{x}_t\mid\mathbf{x}_0)p_{\mathrm{data}}(\mathbf{x}_0)\,d\mathbf{x}_0qt​(xt​)=∫q(xt​∣x0​)pdata​(x0​)dx0​

它是原数据分布被高斯核平滑后的结果。定义 score 为对数密度的梯度：

∇xtlog⁡qt(xt)\nabla_{\mathbf{x}_t}\log q_t(\mathbf{x}_t)∇xt​​logqt​(xt​)

score 指向“概率更高的方向”。在加噪分布上，它告诉我们从当前带噪图像往哪里走，能更接近数据流形。

对单个 x0\mathbf{x}_0x0​，条件 score 是

∇xtlog⁡q(xt∣x0)=−ϵ1−αˉt\nabla_{\mathbf{x}_t}\log q(\mathbf{x}_t\mid\mathbf{x}_0) = -\frac{\boldsymbol{\epsilon}}{\sqrt{1-\bar\alpha_t}}∇xt​​logq(xt​∣x0​)=−1−αˉt​​ϵ​

∇xtlog⁡qt(xt)=−E[ϵ∣xt]1−αˉt\nabla_{\mathbf{x}_t}\log q_t(\mathbf{x}_t) = -\frac{\mathbb{E}[\boldsymbol{\epsilon}\mid\mathbf{x}_t]}{\sqrt{1-\bar\alpha_t}}∇xt​​logqt​(xt​)=−1−αˉt​​E[ϵ∣xt​]​

ϵθ(xt,t)≈E[ϵ∣xt]\boldsymbol{\epsilon}_\theta(\mathbf{x}_t,t) \approx \mathbb{E}[\boldsymbol{\epsilon}\mid\mathbf{x}_t]ϵθ​(xt​,t)≈E[ϵ∣xt​]

ϵθ(xt,t)≈−1−αˉt ∇xtlog⁡qt(xt)\boldsymbol{\epsilon}_\theta(\mathbf{x}_t,t) \approx -\sqrt{1-\bar\alpha_t}\, \nabla_{\mathbf{x}_t}\log q_t(\mathbf{x}_t)ϵθ​(xt​,t)≈−1−αˉt​​∇xt​​logqt​(xt​)

所以预测噪声 = 估计 score，只差一个与 ttt 有关的缩放。

在连续时间极限下，逆向过程可以写成随机微分方程：

DDPM 的离散逆向链，就是对这个过程的近似。采样时沿着 score 走，本质上是在做退火的 Langevin 动力学：先在大噪声下确定粗结构，再在小噪声下补细节。

这也解释了为什么“预测噪声”不是目的：它是估计数据分布梯度的一种参数化方式。网络学的是一整个随 ttt 变化的向量场，而不是某一张图。

有了 μθ\boldsymbol{\mu}_\thetaμθ​，逆向一步就是

这里每一步都保留随机性。这个随机项不是装饰：它让采样从条件后验中抽样，而不是只取条件均值；不同的 xT\mathbf{x}_TxT​ 会走出不同轨迹，因此同一模型可以生成很多张不同的图。

08为什么有效，以及它不保证什么 #

为什么有效 #

  • 分布传输：前向过程把复杂数据分布变成简单高斯；逆向过程学习这个传输的逆。若网络完美，逆向链的边际分布就与真实数据分布一致。
  • 从粗到细：高噪声阶段 score 只包含大尺度结构，低噪声阶段才包含纹理细节；多步采样相当于不断细化。
  • 不是查表：训练覆盖所有 x0\mathbf{x}_0x0​、ttt、ϵ\boldsymbol{\epsilon}ϵ，网络学的是条件期望/score 场，而不是某张训练图。
  • 随机性带来多样性：每步注入校准噪声，让采样覆盖分布，而不是塌缩到一个均值。

它不保证什么 #

  • 无条件 DDPM 不保证输出是某张“原来的图”。采样时没有原图输入，只有随机 xT\mathbf{x}_TxT​；
  • 它不保证生成用户想要的语义。没有类别、文本或参考图条件时，只能从训练数据所在的领域里随机采样；
  • 它不保证小步数下质量不变。步数太少、调度不匹配、模型容量不足都会导致模糊或伪影；
  • 如果从带噪原图出发，逆向过程会保留原图信息，这时才更接近“重建/修复”。
