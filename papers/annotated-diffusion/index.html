在这篇博客中，我们将深入探讨去噪扩散概率模型（Denoising Diffusion Probabilistic Models，DDPM），也就是大家常说的扩散模型、基于分数的生成模型，或者简单地说——自编码器。近年来，研究者借助这类模型在（无条件 / 条件）图像、音频和视频生成上取得了令人瞩目的成果。写作时较为流行的例子包括 OpenAI 的 GLIDE 和 DALL·E 2、海德堡大学的 Latent Diffusion，以及 Google Brain 的 ImageGen。

我们将以 Ho 等人（2020） 的原始 DDPM 论文为主线，参考 Phil Wang 的实现（它本身又基于原始 TensorFlow 实现），用 PyTorch 一步步实现扩散模型。值得注意的是，扩散用于生成建模的想法其实早在 Sohl-Dickstein 等人（2015） 的工作中就已提出。但直到 Song 等人（2019，斯坦福大学） 以及随后 Ho 等人（2020，Google Brain） 各自独立改进这一方法之后，它才真正大放异彩。

扩散模型有多种观察视角。本文采用离散时间（隐变量模型）视角，但也建议你了解其他视角。

01什么是扩散模型？#

如果把（去噪）扩散模型与其他生成模型——例如 Normalizing Flows、GAN 或 VAE——放在一起比较，它其实并不复杂：这些模型都要把某种简单分布中的噪声转换为数据样本。扩散模型也是如此：神经网络学习如何从纯噪声出发，逐步对数据去噪。

具体到图像，整个设置包含两个过程：

  • 一个由我们选定的、固定（或预定义）的前向扩散过程 qqq：它逐步向图像加入高斯噪声，直到图像变成纯噪声；
  • 一个学习得到的逆向去噪扩散过程 pθp_\thetapθ​：训练神经网络从纯噪声出发逐步去噪，直到得到一张真正的图像。

前向过程和逆向过程都由 ttt 索引，并在有限的 TTT 个时间步内完成（DDPM 作者取 T=1000T=1000T=1000）。从 t=0t=0t=0 开始，我们从数据分布中采样一张真实图像 x0\mathbf{x}_0x0​（比如 ImageNet 里的一只猫）；前向过程在每个时间步 ttt 从高斯分布中采样噪声，并把它加到上一时间步的图像上。只要 TTT 足够大、每个时间步的加噪调度足够合理，经过这一渐进过程，到了 t=Tt=Tt=T 时，数据就会变成所谓的各向同性高斯分布。

02更数学化的形式#

下面把它写得更正式一些，因为最终我们需要一个可处理、可供神经网络优化的损失函数。

设 q(x0)q(\mathbf{x}_0)q(x0​) 为真实数据分布，例如“真实图像”的分布。我们可以从中采样得到一张图像 x0∼q(x0)\mathbf{x}_0 \sim q(\mathbf{x}_0)x0​∼q(x0​)。定义前向扩散过程 q(xt∣xt−1)q(\mathbf{x}_t | \mathbf{x}_{t-1})q(xt​∣xt−1​)：它按照已知的方差调度 0<β1<β2<...<βT<10 < \beta_1 < \beta_2 < ... < \beta_T < 10<β1​<β2​<...<βT​<1，在每个时间步 ttt 加入高斯噪声：

q(xt∣xt−1)=N(xt;1−βtxt−1,βtI).q(\mathbf{x}_t | \mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1 - \beta_t} \mathbf{x}_{t-1}, \beta_t \mathbf{I}).q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I).

回顾一下：正态分布（也称高斯分布）由两个参数定义——均值 μ\muμ 和方差 σ2≥0\sigma^2 \geq 0σ2≥0。基本上，时间步 ttt 得到的每张新图像（比上一张略微更嘈杂）都服从一个条件高斯分布，其均值 μt=1−βtxt−1\mathbf{\mu}_t = \sqrt{1 - \beta_t} \mathbf{x}_{t-1}μt​=1−βt​​xt−1​，方差 σt2=βt\sigma^2_t = \beta_tσt2​=βt​。具体做法是采样 ϵ∼N(0,I)\mathbf{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})ϵ∼N(0,I)，再令 xt=1−βtxt−1+βtϵ\mathbf{x}_t = \sqrt{1 - \beta_t} \mathbf{x}_{t-1} + \sqrt{\beta_t} \mathbf{\epsilon}xt​=1−βt​​xt−1​+βt​​ϵ。

注意，βt\beta_tβt​ 并不是每个时间步都相同（这也是下标 ttt 存在的原因）——实际上我们定义的是所谓的“方差调度”，它可以线性、二次、余弦等（后文会看到），有点像学习率调度。

因此，从 x0\mathbf{x}_0x0​ 出发，我们依次得到 x1,...,xt,...,xT\mathbf{x}_1, ..., \mathbf{x}_t, ..., \mathbf{x}_Tx1​,...,xt​,...,xT​。只要调度设置得当，xT\mathbf{x}_TxT​ 就是纯高斯噪声。

现在，如果我们知道条件分布 p(xt−1∣xt)p(\mathbf{x}_{t-1} | \mathbf{x}_t)p(xt−1​∣xt​)，就可以反向运行这个过程：先采样一些随机高斯噪声 xT\mathbf{x}_TxT​，再逐步“去噪”，最终得到来自真实分布的样本 x0\mathbf{x}_0x0​。

但我们并不知道 p(xt−1∣xt)p(\mathbf{x}_{t-1} | \mathbf{x}_t)p(xt−1​∣xt​)。要计算这个条件概率，需要知道所有可能图像的分布，因此它是难解的（intractable）。于是，我们借助神经网络来近似（学习）这个条件概率分布，记为 pθ(xt−1∣xt)p_\theta(\mathbf{x}_{t-1} | \mathbf{x}_t)pθ​(xt−1​∣xt​)，其中 θ\thetaθ 是神经网络参数，通过梯度下降更新。

好，现在我们需要一个神经网络来表示逆向过程的条件概率分布。如果假设逆向过程同样是高斯分布，那么别忘了任何高斯分布都由两个参数定义：

  • 由 μθ\mu_\thetaμθ​ 参数化的均值；
  • 由 Σθ\Sigma_\thetaΣθ​ 参数化的方差。

所以可以把过程参数化为

pθ(xt−1∣xt)=N(xt−1;μθ(xt,t),Σθ(xt,t))p_\theta(\mathbf{x}_{t-1} | \mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \mu_\theta(\mathbf{x}_{t}, t), \Sigma_\theta(\mathbf{x}_{t}, t))pθ​(xt−1​∣xt​)=N(xt−1​;μθ​(xt​,t),Σθ​(xt​,t))

其中均值和方差也都以噪声水平 ttt 为条件。

因此，神经网络需要学习 / 表示均值和方差。不过 DDPM 作者决定固定方差，只让神经网络学习（表示）这个条件概率分布的均值 μθ\mu_\thetaμθ​。论文中写道：

首先，我们令 Σθ(xt,t)=σt2I\Sigma_\theta(\mathbf{x}_t, t) = \sigma^2_t \mathbf{I}Σθ​(xt​,t)=σt2​I，其中 σt2\sigma^2_tσt2​ 是不参与训练、仅依赖于时间的常数。实验表明，σt2=βt\sigma^2_t = \beta_tσt2​=βt​ 和 σt2=β~t\sigma^2_t = \tilde{\beta}_tσt2​=β~​t​（见论文）都能取得相似的结果。

后来，Improved diffusion models 论文对此做了改进：神经网络除了均值，也会学习逆向过程的方差。

所以接下来我们继续假设：神经网络只需要学习 / 表示这个条件概率分布的均值。

03定义目标函数（通过重参数化均值）#

为了推导学习逆向过程均值的目标函数，作者注意到 qqq 和 pθp_\thetapθ​ 的组合可以看作一个变分自编码器（VAE）(Kingma 等，2013)。因此，可以使用变分下界（variational lower bound，也叫 ELBO）来最小化相对于真实数据样本 x0\mathbf{x}_0x0​ 的负对数似然（ELBO 的细节请参阅 VAE 论文）。结果表明，这个过程对应的 ELBO 是每个时间步损失之和：L=L0+L1+...+LTL = L_0 + L_1 + ... + L_TL=L0​+L1​+...+LT​。由于前向 qqq 过程和逆向过程的构造方式，损失中的每一项（除 L0L_0L0​ 外）实际上都是两个高斯分布之间的 KL 散度，而它可以显式写成关于均值的 L2 损失！

如 Sohl-Dickstein 等人所示，构造出的前向过程 qqq 有一个直接结果：给定 x0\mathbf{x}_0x0​，我们可以在任意噪声水平上直接采样 xt\mathbf{x}_txt​（因为高斯分布之和仍是高斯分布）。这非常方便：不必反复应用 qqq 才能得到 xt\mathbf{x}_txt​。我们有

q(xt∣x0)=N(xt;αˉtx0,(1−αˉt)I)q(\mathbf{x}_t | \mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; \sqrt{\bar{\alpha}_t} \mathbf{x}_0, (1- \bar{\alpha}_t) \mathbf{I})q(xt​∣x0​)=N(xt​;αˉt​​x0​,(1−αˉt​)I)

其中 αt:=1−βt\alpha_t := 1 - \beta_tαt​:=1−βt​，αˉt:=Πs=1tαs\bar{\alpha}_t := \Pi_{s=1}^{t} \alpha_sαˉt​:=Πs=1t​αs​。我们把这个等式称为“优良性质”（nice property）。它意味着，只要采样高斯噪声、做适当缩放，再加到 x0\mathbf{x}_0x0​ 上，就能直接得到 xt\mathbf{x}_txt​。注意，αˉt\bar{\alpha}_tαˉt​ 是已知的 βt\beta_tβt​ 方差调度的函数，因此也是已知的，可以预先计算。这样一来，训练时我们就可以随机优化损失函数 LLL 中的某些项（换句话说，训练时随机采样 ttt，只优化 LtL_tLt​）。

如 Ho 等人所示，这个性质还有一个妙处：经过一些数学推导（细节可参阅这篇优秀的博客），我们可以重参数化均值，让神经网络学习（预测）在噪声水平 ttt 下加入的噪声（通过网络 ϵθ(xt,t)\mathbf{\epsilon}_\theta(\mathbf{x}_t, t)ϵθ​(xt​,t)），这些项构成 KL 损失。这意味着神经网络变成了噪声预测器，而不是（直接）预测均值。均值可以这样计算：

μθ(xt,t)=1αt(xt−βt1−αˉtϵθ(xt,t))\mathbf{\mu}_\theta(\mathbf{x}_t, t) = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t - \frac{\beta_t}{\sqrt{1- \bar{\alpha}_t}} \mathbf{\epsilon}_\theta(\mathbf{x}_t, t) \right)μθ​(xt​,t)=αt​​1​(xt​−1−αˉt​​βt​​ϵθ​(xt​,t))

最终的目标函数 LtL_tLt​ 如下（给定随机时间步 ttt 和 ϵ∼N(0,I)\mathbf{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})ϵ∼N(0,I)）：

∥ϵ−ϵθ(xt,t)∥2=∥ϵ−ϵθ(αˉtx0+1−αˉtϵ,t)∥2.\| \mathbf{\epsilon} - \mathbf{\epsilon}_\theta(\mathbf{x}_t, t) \|^2 = \left\| \mathbf{\epsilon} - \mathbf{\epsilon}_\theta\left( \sqrt{\bar{\alpha}_t} \mathbf{x}_0 + \sqrt{1- \bar{\alpha}_t} \mathbf{\epsilon}, t \right) \right\|^2.∥ϵ−ϵθ​(xt​,t)∥2=​ϵ−ϵθ​(αˉt​​x0​+1−αˉt​​ϵ,t)​2.

这里，x0\mathbf{x}_0x0​ 是初始的（真实、未损坏的）图像，ttt 则由固定的前向过程采样得到。ϵ\mathbf{\epsilon}ϵ 是在时间步 ttt 采样的纯噪声，ϵθ(xt,t)\mathbf{\epsilon}_\theta(\mathbf{x}_t, t)ϵθ​(xt​,t) 是我们的神经网络。网络通过真实高斯噪声与预测噪声之间的简单均方误差（MSE）进行优化。

  3. 均匀采样时间步 t∼Uniform({1,…,T})t \sim \mathrm{Uniform}(\{1,\ldots,T\})t∼Uniform({1,…,T})；

换句话说：

  • 从真实、未知且可能非常复杂的数据分布 q(x0)q(\mathbf{x}_0)q(x0​) 中随机采样 x0\mathbf{x}_0x0​；
  • 在 111 到 TTT 之间均匀采样一个噪声水平 ttt（即随机时间步）；
  • 从高斯分布采样噪声，并在噪声水平 ttt 上用该噪声破坏输入（利用上面定义的优良性质）；
  • 训练神经网络根据被破坏的图像 xt\mathbf{x}_txt​ 预测这份噪声（也就是基于已知调度 βt\beta_tβt​ 加到 x0\mathbf{x}_0x0​ 上的噪声）。

实际上，这些操作都在数据批次上进行，因为训练神经网络通常使用随机梯度下降。

04神经网络#

神经网络需要接收某个时间步的含噪图像，并返回预测的噪声。注意，预测噪声是一个与输入图像尺寸 / 分辨率相同的张量。所以严格来说，网络的输入和输出张量形状相同。那么应该选用什么样的神经网络呢？

这里常用的结构与自编码器非常相似——你可能在典型的“深度学习入门”教程中见过。自编码器在编码器和解码器之间有一个所谓的“瓶颈”层。编码器先把图像编码成更小的隐藏表示，即“瓶颈”；解码器再把该隐藏表示解码回真实图像。这迫使网络只在瓶颈层保留最重要的信息。

在架构选择上，DDPM 作者采用了 U-Net，由 (Ronneberger 等，2015) 提出（当时它在医学图像分割任务上取得了最先进的结果）。和任何自编码器一样，这个网络中间也有一个瓶颈，确保网络只学习最重要的信息。重要的是，它在编码器和解码器之间引入了残差连接，大大改善了梯度流动（受 He 等人 2015 年 ResNet 的启发）。

展开：U-Net 图例中文对照
  • input image tile — 输入图像块
  • output segmentation map — 输出分割图
  • conv 3×3, ReLU — 3×3 卷积 + ReLU
  • copy and crop — 复制并裁剪（跳跃连接）
  • max pool 2×2 — 2×2 最大池化
  • up-conv 2×2 — 2×2 上卷积
  • conv 1×1 — 1×1 卷积

如你所见，U-Net 模型首先对输入进行下采样（即降低输入的空间分辨率），然后再进行上采样。

下面我们一步步实现这个网络。

网络辅助函数#

首先定义一些辅助函数和类，稍后实现神经网络时会用到。重要的是，我们定义了一个 Residual 模块，它把输入加到某个函数的输出上（换句话说，为某个函数添加残差连接）。

我们还为下采样和上采样操作定义了别名。

Python
def exists(x):
    return x is not None

def default(val, d):
    if exists(val):
        return val
    return d() if isfunction(d) else d


def num_to_groups(num, divisor):
    groups = num // divisor
    remainder = num % divisor
    arr = [divisor] * groups
    if remainder > 0:
        arr.append(remainder)
    return arr


class Residual(nn.Module):
    def __init__(self, fn):
        super().__init__()
        self.fn = fn

    def forward(self, x, *args, **kwargs):
        return self.fn(x, *args, **kwargs) + x


def Upsample(dim, dim_out=None):
    return nn.Sequential(
        nn.Upsample(scale_factor=2, mode="nearest"),
        nn.Conv2d(dim, default(dim_out, dim), 3, padding=1),
    )


def Downsample(dim, dim_out=None):
    # 不再使用带步长的卷积或池化
    return nn.Sequential(
        Rearrange("b c (h p1) (w p2) -> b (c p1 p2) h w", p1=2, p2=2),
        nn.Conv2d(dim * 4, default(dim_out, dim), 1),
    )

位置嵌入#

由于神经网络的参数在时间（噪声水平）上共享，作者使用正弦位置嵌入来编码 ttt，这一做法受 Transformer (Vaswani 等，2017) 启发。这样，网络就能“知道”自己正在处理批次中每张图像的哪个时间步（噪声水平）。

SinusoidalPositionEmbeddings 模块接收形状为 (batch_size, 1) 的张量（即批次中若干张含噪图像的噪声水平），并将其转换为形状 (batch_size, dim) 的张量，其中 dim 是位置嵌入的维度。这个嵌入随后会被加到每个残差块中，后面会看到。

Python
class SinusoidalPositionEmbeddings(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, time):
        device = time.device
        half_dim = self.dim // 2
        embeddings = math.log(10000) / (half_dim - 1)
        embeddings = torch.exp(torch.arange(half_dim, device=device) * -embeddings)
        embeddings = time[:, None] * embeddings[None, :]
        embeddings = torch.cat((embeddings.sin(), embeddings.cos()), dim=-1)
        return embeddings

ResNet 块#

接下来定义 U-Net 的核心构建块。DDPM 作者采用了 Wide ResNet 块 (Zagoruyko 等，2016)，但 Phil Wang 把标准卷积层换成了“权重标准化”版本，它与组归一化结合时效果更好（细节见 Kolesnikov 等，2019）。

Python
class WeightStandardizedConv2d(nn.Conv2d):
    """
    https://arxiv.org/abs/1903.10520
    据称，权重标准化可与组归一化产生协同效果
    """

    def forward(self, x):
        eps = 1e-5 if x.dtype == torch.float32 else 1e-3

        weight = self.weight
        mean = reduce(weight, "o ... -> o 1 1 1", "mean")
        var = reduce(weight, "o ... -> o 1 1 1", partial(torch.var, unbiased=False))
        normalized_weight = (weight - mean) * (var + eps).rsqrt()

        return F.conv2d(
            x,
            normalized_weight,
            self.bias,
            self.stride,
            self.padding,
            self.dilation,
            self.groups,
        )


class Block(nn.Module):
    def __init__(self, dim, dim_out, groups=8):
        super().__init__()
        self.proj = WeightStandardizedConv2d(dim, dim_out, 3, padding=1)
        self.norm = nn.GroupNorm(groups, dim_out)
        self.act = nn.SiLU()

    def forward(self, x, scale_shift=None):
        x = self.proj(x)
        x = self.norm(x)

        if exists(scale_shift):
            scale, shift = scale_shift
            x = x * (scale + 1) + shift

        x = self.act(x)
        return x


class ResnetBlock(nn.Module):
    """https://arxiv.org/abs/1512.03385"""

    def __init__(self, dim, dim_out, *, time_emb_dim=None, groups=8):
        super().__init__()
        self.mlp = (
            nn.Sequential(nn.SiLU(), nn.Linear(time_emb_dim, dim_out * 2))
            if exists(time_emb_dim)
            else None
        )

        self.block1 = Block(dim, dim_out, groups=groups)
        self.block2 = Block(dim_out, dim_out, groups=groups)
        self.res_conv = nn.Conv2d(dim, dim_out, 1) if dim != dim_out else nn.Identity()

    def forward(self, x, time_emb=None):
        scale_shift = None
        if exists(self.mlp) and exists(time_emb):
            time_emb = self.mlp(time_emb)
            time_emb = rearrange(time_emb, "b c -> b c 1 1")
            scale_shift = time_emb.chunk(2, dim=1)

        h = self.block1(x, scale_shift=scale_shift)
        h = self.block2(h)
        return h + self.res_conv(x)

注意力模块#

接着定义注意力模块，DDPM 作者把它加在卷积块之间。注意力是著名的 Transformer 架构的基本构建块 (Vaswani 等，2017)，已在 AI 的多个领域取得巨大成功，从 NLP、视觉到蛋白质折叠。Phil Wang 采用了两种注意力变体：一种是常规的多头自注意力（Transformer 中使用的那种），另一种是线性注意力变体 (Shen 等，2018)，其时间和内存需求随序列长度线性增长，而常规注意力则是二次增长。

关于注意力机制的详细解释，推荐阅读 Jay Alammar 的精彩博客。

Python
class Attention(nn.Module):
    def __init__(self, dim, heads=4, dim_head=32):
        super().__init__()
        self.scale = dim_head**-0.5
        self.heads = heads
        hidden_dim = dim_head * heads
        self.to_qkv = nn.Conv2d(dim, hidden_dim * 3, 1, bias=False)
        self.to_out = nn.Conv2d(hidden_dim, dim, 1)

    def forward(self, x):
        b, c, h, w = x.shape
        qkv = self.to_qkv(x).chunk(3, dim=1)
        q, k, v = map(
            lambda t: rearrange(t, "b (h c) x y -> b h c (x y)", h=self.heads), qkv
        )
        q = q * self.scale

        sim = einsum("b h d i, b h d j -> b h i j", q, k)
        sim = sim - sim.amax(dim=-1, keepdim=True).detach()
        attn = sim.softmax(dim=-1)

        out = einsum("b h i j, b h d j -> b h i d", attn, v)
        out = rearrange(out, "b h (x y) d -> b (h d) x y", x=h, y=w)
        return self.to_out(out)

class LinearAttention(nn.Module):
    def __init__(self, dim, heads=4, dim_head=32):
        super().__init__()
        self.scale = dim_head**-0.5
        self.heads = heads
        hidden_dim = dim_head * heads
        self.to_qkv = nn.Conv2d(dim, hidden_dim * 3, 1, bias=False)

        self.to_out = nn.Sequential(nn.Conv2d(hidden_dim, dim, 1), 
                                    nn.GroupNorm(1, dim))

    def forward(self, x):
        b, c, h, w = x.shape
        qkv = self.to_qkv(x).chunk(3, dim=1)
        q, k, v = map(
            lambda t: rearrange(t, "b (h c) x y -> b h c (x y)", h=self.heads), qkv
        )

        q = q.softmax(dim=-2)
        k = k.softmax(dim=-1)

        q = q * self.scale
        context = torch.einsum("b h d n, b h e n -> b h d e", k, v)

        out = torch.einsum("b h d e, b h d n -> b h e n", context, q)
        out = rearrange(out, "b h c (x y) -> b (h c) x y", h=self.heads, x=h, y=w)
        return self.to_out(out)

组归一化#

DDPM 作者在 U-Net 的卷积 / 注意力层之间穿插组归一化 (Wu 等，2018)。下面定义 PreNorm 类，用于在注意力层之前应用组归一化，后文会看到。注意，Transformer 中应该在注意力之前还是之后做归一化，一直存在争论。

Python
class PreNorm(nn.Module):
    def __init__(self, dim, fn):
        super().__init__()
        self.fn = fn
        self.norm = nn.GroupNorm(1, dim)

    def forward(self, x):
        x = self.norm(x)
        return self.fn(x)

条件 U-Net#

现在所有构建块（位置嵌入、ResNet 块、注意力和组归一化）都定义好了，是时候定义整个神经网络了。回忆一下，网络 ϵθ(xt,t)\mathbf{\epsilon}_\theta(\mathbf{x}_t, t)ϵθ​(xt​,t) 的工作是：接收一批含噪图像及其各自的噪声水平，输出加到输入上的噪声。更正式地说：

  • 网络接收形状为 (batch_size, num_channels, height, width) 的一批含噪图像，以及形状为 (batch_size, 1) 的一批噪声水平作为输入，返回形状为 (batch_size, num_channels, height, width) 的张量。

网络按如下方式构建：

  • 首先，在含噪图像批次上应用一个卷积层，并为噪声水平计算位置嵌入；
  • 接着，应用一系列下采样阶段。每个下采样阶段包含 2 个 ResNet 块 + 组归一化 + 注意力 + 残差连接 + 一个下采样操作；
  • 在网络中部，再次应用 ResNet 块，并与注意力交错；
  • 然后，应用一系列上采样阶段。每个上采样阶段包含 2 个 ResNet 块 + 组归一化 + 注意力 + 残差连接 + 一个上采样操作；
  • 最后，应用一个 ResNet 块，再接一个卷积层。

归根结底，神经网络就像搭乐高积木一样堆叠层（但理解它们如何工作很重要）。

Python
class Unet(nn.Module):
    def __init__(
        self,
        dim,
        init_dim=None,
        out_dim=None,
        dim_mults=(1, 2, 4, 8),
        channels=3,
        self_condition=False,
        resnet_block_groups=4,
    ):
        super().__init__()

        # 确定各层维度
        self.channels = channels
        self.self_condition = self_condition
        input_channels = channels * (2 if self_condition else 1)

        init_dim = default(init_dim, dim)
        self.init_conv = nn.Conv2d(input_channels, init_dim, 1, padding=0) # changed to 1 and 0 from 7,3

        dims = [init_dim, *map(lambda m: dim * m, dim_mults)]
        in_out = list(zip(dims[:-1], dims[1:]))

        block_klass = partial(ResnetBlock, groups=resnet_block_groups)

        # 时间嵌入
        time_dim = dim * 4

        self.time_mlp = nn.Sequential(
            SinusoidalPositionEmbeddings(dim),
            nn.Linear(dim, time_dim),
            nn.GELU(),
            nn.Linear(time_dim, time_dim),
        )

        # 网络层
        self.downs = nn.ModuleList([])
        self.ups = nn.ModuleList([])
        num_resolutions = len(in_out)

        for ind, (dim_in, dim_out) in enumerate(in_out):
            is_last = ind >= (num_resolutions - 1)

            self.downs.append(
                nn.ModuleList(
                    [
                        block_klass(dim_in, dim_in, time_emb_dim=time_dim),
                        block_klass(dim_in, dim_in, time_emb_dim=time_dim),
                        Residual(PreNorm(dim_in, LinearAttention(dim_in))),
                        Downsample(dim_in, dim_out)
                        if not is_last
                        else nn.Conv2d(dim_in, dim_out, 3, padding=1),
                    ]
                )
            )

        mid_dim = dims[-1]
        self.mid_block1 = block_klass(mid_dim, mid_dim, time_emb_dim=time_dim)
        self.mid_attn = Residual(PreNorm(mid_dim, Attention(mid_dim)))
        self.mid_block2 = block_klass(mid_dim, mid_dim, time_emb_dim=time_dim)

        for ind, (dim_in, dim_out) in enumerate(reversed(in_out)):
            is_last = ind == (len(in_out) - 1)

            self.ups.append(
                nn.ModuleList(
                    [
                        block_klass(dim_out + dim_in, dim_out, time_emb_dim=time_dim),
                        block_klass(dim_out + dim_in, dim_out, time_emb_dim=time_dim),
                        Residual(PreNorm(dim_out, LinearAttention(dim_out))),
                        Upsample(dim_out, dim_in)
                        if not is_last
                        else nn.Conv2d(dim_out, dim_in, 3, padding=1),
                    ]
                )
            )

        self.out_dim = default(out_dim, channels)

        self.final_res_block = block_klass(dim * 2, dim, time_emb_dim=time_dim)
        self.final_conv = nn.Conv2d(dim, self.out_dim, 1)

    def forward(self, x, time, x_self_cond=None):
        if self.self_condition:
            x_self_cond = default(x_self_cond, lambda: torch.zeros_like(x))
            x = torch.cat((x_self_cond, x), dim=1)

        x = self.init_conv(x)
        r = x.clone()

        t = self.time_mlp(time)

        h = []

        for block1, block2, attn, downsample in self.downs:
            x = block1(x, t)
            h.append(x)

            x = block2(x, t)
            x = attn(x)
            h.append(x)

            x = downsample(x)

        x = self.mid_block1(x, t)
        x = self.mid_attn(x)
        x = self.mid_block2(x, t)

        for block1, block2, attn, upsample in self.ups:
            x = torch.cat((x, h.pop()), dim=1)
            x = block1(x, t)

            x = torch.cat((x, h.pop()), dim=1)
            x = block2(x, t)
            x = attn(x)

            x = upsample(x)

        x = torch.cat((x, r), dim=1)

        x = self.final_res_block(x, t)
        return self.final_conv(x)

05定义前向扩散过程#

前向扩散过程在 TTT 个时间步内逐步向真实分布中的图像添加噪声。这一过程遵循方差调度。原始 DDPM 作者采用了线性调度：

我们把前向过程的方差设为常数，从 β1=10−4\beta_1 = 10^{−4}β1​=10−4 线性增加到 βT=0.02\beta_T = 0.02βT​=0.02。

不过，Nichol 等人（2021）表明，采用余弦调度可以获得更好的结果。

下面定义 TTT 个时间步的多种调度（稍后选择其中一种）。

Python
def cosine_beta_schedule(timesteps, s=0.008):
    """
    余弦调度，提出于 https://arxiv.org/abs/2102.09672
    """
    steps = timesteps + 1
    x = torch.linspace(0, timesteps, steps)
    alphas_cumprod = torch.cos(((x / timesteps) + s) / (1 + s) * torch.pi * 0.5) ** 2
    alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
    betas = 1 - (alphas_cumprod[1:] / alphas_cumprod[:-1])
    return torch.clip(betas, 0.0001, 0.9999)

def linear_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    return torch.linspace(beta_start, beta_end, timesteps)

def quadratic_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    return torch.linspace(beta_start**0.5, beta_end**0.5, timesteps) ** 2

def sigmoid_beta_schedule(timesteps):
    beta_start = 0.0001
    beta_end = 0.02
    betas = torch.linspace(-6, 6, timesteps)
    return torch.sigmoid(betas) * (beta_end - beta_start) + beta_start

首先，我们使用线性调度，取 T=300T=300T=300 个时间步，并定义后面会用到的、由 βt\beta_tβt​ 导出的各种变量，例如方差累积乘积 αˉt\bar{\alpha}_tαˉt​。下面的每个变量都是一维张量，存储从 ttt 到 TTT 的值。重要的是，我们还定义了 extract 函数，用于根据一批索引取出对应的 ttt 值。

Python
timesteps = 300

# 定义 beta 调度

# 定义 alpha

alphas_cumprod = torch.cumprod(alphas, axis=0)
alphas_cumprod_prev = F.pad(alphas_cumprod[:-1], (1, 0), value=1.0)
sqrt_recip_alphas = torch.sqrt(1.0 / alphas)

# 计算扩散过程 q(x_t | x_{t-1}) 等所需项
sqrt_alphas_cumprod = torch.sqrt(alphas_cumprod)
sqrt_one_minus_alphas_cumprod = torch.sqrt(1. - alphas_cumprod)

# 计算后验 q(x_{t-1} | x_t, x_0) 所需项
posterior_variance = betas * (1. - alphas_cumprod_prev) / (1. - alphas_cumprod)

def extract(a, t, x_shape):
    batch_size = t.shape[0]
    out = a.gather(-1, t.cpu())
    return out.reshape(batch_size, *((1,) * (len(x_shape) - 1))).to(t.device)

def p_losses(denoise_model, x_start, t, noise=None, loss_type="l1"):

07采样#

训练过程中我们会从模型采样（以跟踪进度），因此下面定义采样代码。论文把采样总结为算法 2：

展开：算法 2 的中文步骤
  1. 采样初始噪声 xT∼N(0,I)\mathbf{x}_T \sim \mathcal{N}(\mathbf{0}, \mathbf{I})xT​∼N(0,I)；
  2. for t=T,…,1t = T, \ldots, 1t=T,…,1 do
  3. 若 t>1t > 1t>1，采样 z∼N(0,I)\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})z∼N(0,I)；否则令 z=0\mathbf{z} = \mathbf{0}z=0；
  4. 计算 xt−1=1αt(xt−1−αt1−αˉtϵθ(xt,t))+σtz\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \mathbf{\epsilon}_\theta(\mathbf{x}_t, t) \right) + \sigma_t \mathbf{z}xt−1​=αt​​1​(xt​−1−αˉt​​1−αt​​ϵθ​(xt​,t))+σt​z；
  5. end for
  6. 返回 x0\mathbf{x}_0x0​。

从扩散模型生成新图像，就是逆转扩散过程：从 TTT 开始，从高斯分布采样纯噪声，然后利用神经网络逐步去噪（使用它学到的条件概率），直到时间步 t=0t=0t=0。如上所示，把均值的重参数化形式代入，并用噪声预测器，就能得到略微少噪一点的图像 xt−1\mathbf{x}_{t-1}xt−1​。记住，方差是提前已知的。

理想情况下，最终得到的图像看起来像是来自真实数据分布。

下面的代码实现了这一点。

Python
@torch.no_grad()
def p_sample(model, x, t, t_index):
    betas_t = extract(betas, t, x.shape)
    sqrt_one_minus_alphas_cumprod_t = extract(
        sqrt_one_minus_alphas_cumprod, t, x.shape
    )
    sqrt_recip_alphas_t = extract(sqrt_recip_alphas, t, x.shape)
    
    # 论文中的式 (11)
    # 用模型（噪声预测器）预测均值
    model_mean = sqrt_recip_alphas_t * (
        x - betas_t * model(x, t) / sqrt_one_minus_alphas_cumprod_t
    )

    if t_index == 0:
        return model_mean
    else:
        posterior_variance_t = extract(posterior_variance, t, x.shape)
        noise = torch.randn_like(x)
        # 算法 2 第 4 行：
        return model_mean + torch.sqrt(posterior_variance_t) * noise 

# 算法 2（同时返回所有中间图像）
@torch.no_grad()
def p_sample_loop(model, shape):
    device = next(model.parameters()).device

    b = shape[0]
    # 从纯噪声开始（批中每个样本各一份）
    img = torch.randn(shape, device=device)
    imgs = []

    for i in tqdm(reversed(range(0, timesteps)), desc='sampling loop time step', total=timesteps):
        img = p_sample(model, img, torch.full((b,), i, device=device, dtype=torch.long), i)
        imgs.append(img.cpu().numpy())
    return imgs

@torch.no_grad()
def sample(model, image_size, batch_size=16, channels=3):
    return p_sample_loop(model, shape=(batch_size, channels, image_size, image_size))

注意，上面的代码是原始实现的简化版。我们发现这个简化版（与论文算法 2 一致）效果与原始更复杂的实现一样好，后者使用了 clipping。

from pathlib import Path

def num_to_groups(num, divisor):
    groups = num // divisor
    remainder = num % divisor
    arr = [divisor] * groups
    if remainder > 0:
        arr.append(remainder)
    return arr

10延伸阅读#

DDPM 论文表明，扩散模型是（无条件）图像生成的一个有前景的方向。此后，这一方向（极大地）得到了改进，尤其是在文本条件图像生成方面。下面列出一些重要（但远非完整）的后续工作：

  • Improved Denoising Diffusion Probabilistic Models (Nichol 等，2021)：发现除了均值之外，再学习条件分布的方差，有助于提升性能。
  • Cascaded Diffusion Models for High Fidelity Image Generation (Ho 等，2021)：提出级联扩散，用多个扩散模型组成的流水线逐步生成更高分辨率的图像，以实现高保真图像合成。
  • Diffusion Models Beat GANs on Image Synthesis (Dhariwal 等，2021)：通过改进 U-Net 架构并引入分类器引导，证明扩散模型可以取得优于当时最先进生成模型的图像样本质量。
  • Classifier-Free Diffusion Guidance (Ho 等，2021)：表明无需额外分类器，只用单个神经网络联合训练条件与无条件扩散模型，也能实现引导。
  • Hierarchical Text-Conditional Image Generation with CLIP Latents（DALL·E 2） (Ramesh 等，2022)：先用一个先验网络把文本描述转换为 CLIP 图像嵌入，再由扩散模型将其解码为图像。
  • Photorealistic Text-to-Image Diffusion Models with Deep Language Understanding（ImageGen） (Saharia 等，2022)：表明将大型预训练语言模型（如 T5）与级联扩散结合，可以在文本到图像合成上取得良好效果。

注意，这份列表只包含截至写作时（2022 年 6 月 7 日）的重要工作。

目前来看，扩散模型的主要（也许是唯一）缺点是需要多次前向传播才能生成一张图像（GAN 等生成模型则不需要）。不过，已有研究可以在少至 10 个去噪步骤内实现高保真生成。
